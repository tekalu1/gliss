# Gliss の使い方

画面の操作・DAW との往復・AI からの使い方の詳しい説明。インストールと最初の一歩は [README](../README.md)。

## 1. 画面を使う

推定の読みは自動分割のノートだけに薄く表示する。はさみで分割・結合したノートや、手で長さ・位置を変えたノートでは表示から外れ、取り消すと戻る。推定のまま「ガイドに合わせる」のタイミングを使うとノート全体で伸縮し、入力・読み込み・音節修正で確定した読みの部分だけ音素単位で伸縮する。部分的に確定したノートでは確定音節だけが音素単位の補正点になる。

設定（最近使ったプロジェクト・前回のプロジェクト・キーとホイールの割り当て・前回の表示範囲・ウィンドウの位置）は `%APPDATA%\Gliss\state.json`。旧称のときの `%APPDATA%\vocal-editor-app\state.json` は、`Gliss` 側にまだ設定が無ければ起動時に写す（元は消さない）。

0. **プロジェクトのファイル**（issue #33。DAW と同じ）: **ファイル > 新規プロジェクト**（Ctrl+N。空のプロジェクト）・**開く…**（Ctrl+O）・**最近使ったプロジェクト**・**保存**（Ctrl+S）・**名前を付けて保存…**（Ctrl+Shift+S）。プロジェクトは 1 つのファイル **`<名前>.gliss`**（保存先は自由。既定は最初のトラックの音声の隣）。
   - **未保存の変更があればタイトルに「*」**（ウィンドウ・タスクバーは「曲名* — Gliss」、上端のバーの中央は「曲名*」）。閉じる・新規・開くの前に「**保存しますか**」（保存 / 保存しない / キャンセル）。保存していない無題は「無題」。
   - **保存しないまま落ちても消えない**: 編集は作業場所（`%LOCALAPPDATA%\Gliss\work\`）に毎回書いているので、同じファイルを開き直すと続きから開く（ステータス行に「保存していない変更の続きから開いた」。いらなければ閉じるときに「保存しない」）。
   - **別のエンジンとの保存競合**: Claude Code などが同じトラックを先に書き換えた場合、画面は最新の状態と履歴を読み直し、今の操作と順番待ちの編集（保存の後に入れた操作も）、古いプレビューを破棄する。ステータス行には「別のエンジン（Claude Code など）がこのトラックを書き換えたので、読み直した。今の操作は当てていない」と出る。表示を確認してから操作し直す。保存（Ctrl+S）と競合の読み直しは編集と同じ順番待ちの中で行い、終わるまで次の操作は始まらない。複数のノートのピッチ・結合のように何回かに分けて当てる操作で、途中で競合したときは「…読み直した。今の操作は一部だけ当たった可能性がある。表示を確かめて」と出る（前の分は当たっている）。準備待ちが期限切れなら「準備中。少し待ってからもう一度」と出る。
   - **音声は `.gliss` に入れず参照する**（絶対パスと、`.gliss` からの相対パス）。プロジェクトのフォルダと音声を一緒に別の場所・別の PC に移しても開ける。見つからない音声はステータス行に出る。**解析のキャッシュは作業場所**（`.gliss` は小さいまま。別の PC で開くと最初の 1 回だけ解析し直す）。
   - 起動すると前回のプロジェクトを開く。何も無ければ空のまま（WAV を落とすか、新規・開く）。
   - **旧形式（issue #33 より前の `projects\<テイク名>-<ハッシュ>\`）もそのまま開ける**: 開く… でその WAV か `session.json` を選ぶ・最近使ったプロジェクト・WAV を落とす（そのテイクの旧形式のプロジェクトがあればそちらが開く）。旧形式は今までどおり編集のたびに自動で保存され、「*」は出ない。**名前を付けて保存すると `.gliss` になる**（以後はそのファイル。同じテイクを開くと `.gliss` の方が開く）。
   - 詳細（ファイル形式・音声を参照にした理由・作業場所・相対パス）は [MCP.md](../engine/docs/MCP.md) §3-3。
1. **開く**: **WAV をウィンドウにドラッグ＆ドロップ**（エクスプローラや DAW から。落とす前はステータス行に案内が出る）すると、新しいプロジェクトのテイクとして開く（開いている間に落とすとトラックとして足す。下の 3）。**ファイル > 開く…**（Ctrl+O）で WAV を選んでも同じ。曲頭 0:00 起点のファイルをそのまま。解析（F0・音符）は 158 秒で約 10 秒、2 回目からはキャッシュで 2 秒。
2. **ファイル > ガイドを開く…** でガイドボーカル WAV（任意）。**Shift を押しながらドロップ**でも重ねられる（テイクと編集はそのまま）。テイクと同じ形（ノートごとの小さな波形＋細い線）でグレーに重なる。
3. **トラック**（画面の上。[track-view.md](track-view.md)）: 1 曲ぶんの複数トラック（ボーカルのテイク複数・ガイド 1 本・伴奏）。上にトラックビュー、下に今のエディター。
   - **足す**: **ファイル > トラックを追加…**（Ctrl+Shift+O）か、開いている間に**ウィンドウへドロップ**（ボーカルなら足して編集対象に。名前に inst・karaoke・オケ・伴奏 などがあれば伴奏として足すだけ。Shift+ドロップはガイドとして）。**足したボーカルのトラックは、選ぶ前に裏で解析しておく**（テイクの音程・歌詞の推定・音素・ガイドとの対応付け。ガイドを変えたときも新しいガイドとの対応付けを先に取る。その間も編集・再生は止まらない。issue #63。[MCP.md](../engine/docs/MCP.md) §3-2）。**外す**・伴奏／ボーカルの切り替え・**名前を変える**は見出しの右クリック（外してもファイルと編集は消さない。Ctrl+Z で同じ位置に戻る）。
   - **見出し**: 名前（クリックで編集対象を切り替え。表示範囲はそのまま）・**ガイドのアイコン**（1 本だけ。もう一度押すと外れる）・**M**（ミュート）・**S**（ソロ）。
   - **準備中の印**（issue #63）: 裏の解析がまだのトラックは、名前の右に小さな印が出る（準備中 = 進み具合の輪、順番待ち = 点線の輪。段階名と % はツールチップ）。済むと消える。準備済みのトラックへの切り替えは 0.1 秒前後で、何も出さない。まだのトラックを選ぶと、準備が終わるまでポップアップで待つ（下の「処理中」）。解析に失敗したトラックは「!」（ガイドとの対応付けの失敗は薄い「!」で、開いて編集できる。位置のままの対応で重ねる）。
   - **並び順**（issue #38）: **見出しを上下にドラッグ**（DAW と同じ）。ドラッグ中から見出しとレーンの行が入れ替わって見え、離すと確定（Ctrl+Z で戻る。取り消しの名前は「トラックの順番」）。並びは見た目だけで、音・編集・ガイドとの対応は変わらない。動かさずに離すのは名前のクリックのまま。MCP は `set_track(index)`。
   - **クリップ**: クリック → そのトラックのクリックした所の歌っているかたまりを下に出す。**上半分**を横にドラッグ → その範囲を下に出す。**下半分を横にドラッグ → 音源全体の位置をずらす**（Fender Studio Pro／Studio One のスマートツールと同じ分け方。非破壊。Shift で細かく、元の位置の近く（30 ms 以内）に吸い付く・Alt で吸い付かない、**時間スナップ（N）がオンならクリップの頭がグリッドに**（Shift で解除）、Ctrl+Z か右クリックの「元の位置に戻す」で戻す。ガイドとの対応はタイムライン上の位置で取り直す）。伴奏をクリックすると再生位置が動くだけ。
   - **Ctrl+O（開く…）は別のプロジェクト（曲）を開く**。今の曲に足すのはドロップかトラックを追加…。
   - **ガイドが重ならないときは理由がステータス行に出る**（「編集中のトラックがガイド。別のトラックを選ぶと重なる」「トラックの見出しのガイドのアイコンでガイドを指定する」など。「ガイドに合わせる」（G）を押したときも同じ理由）。ガイドのトラック自身を編集している間は重ならない。部分的に録り直したテイク（歌っていない所がほぼ無音）でもガイドとの対応付けは落ちない（issue #32）。
   - 外したトラックを同じファイルで足し直すと、前の編集ごと戻る（最初のテイクも）。
   - 下の表示範囲は上に白枠。再生位置とループは上下で共通。上下の境界はドラッグで高さ、ダブルクリックで上を畳む。**Ctrl+ホイールで全トラックの高さ**（28〜96 px。ポインタの所のトラックは動かない）、ふつうのホイールでトラックの縦スクロール。
   - **上の横の表示範囲は下のエディターと別**（issue #39）: 上で **Ctrl+Shift+ホイール = 横ズーム**（ポインタの下の時刻を中心に。最小 0.5 秒）、**Shift+ホイール = 横スクロール**（タッチパッドの横の量も）。割り当ては下のエディターと共通で、ポインタのある側に効く。既定（ズームしていない間）は全体表示で、曲の長さに合わせて広がる（全体より広げると全体表示に戻る）。下の表示範囲の白枠はそのまま描く。**表示 > ズームを戻す** で全体表示に。前回の表示範囲と一緒に覚える（同じテイクのとき）。
   - **再生は全トラックを混ぜて鳴らす**（ガイドも鳴る。ミュート／ソロで重ねたり切り替えたり）。
   - **音量とパン**: トラックの見出しの 2 段目のスライダー（−∞〜+6 dB）とノブ（L100〜R100）。ダブルクリックで 0 dB・中央、Shift で細かく。聞こえ方（再生）だけに効き、書き出しには入らない。
   - **見出しの幅**: 見出しとレーンの境目をドラッグ（ダブルクリックで元の幅）。
4. **歌詞**: 解析すると発声区間ごとに推定の読みが薄く入り、音素境界も出る（評価は [lyrics-auto.md](lyrics-auto.md)）。歌詞レーンの上段で音節をダブルクリックして1音節を直すか、下段をダブルクリックして区間の歌詞を入力できる。**ファイル > 歌詞を読み込む（SVP / MIDI）…** で Synthesizer V の `.svp` または歌詞付き MIDI から録音に対応する区間を確定歌詞として読み込める。複数の歌詞付きトラックは選択する。対応できない区間は保留にして件数を表示する（手順と実ファイルでの精度は [import-svp.md](import-svp.md)）。テキストからの読み込みも可。確定歌詞は推定で上書きされず、Ctrl+Z で戻せる。
   - **聞き取る**（issue #54）: 歌詞レーンで区間（歌詞のある区間、無ければ発声のかたまり）を右クリック →「聞き取る」。音声認識（Whisper large-v3）の結果を**候補**として、その場に薄く出す（語は聞こえた時刻に置く。ステータス行に文字・読み・確信・今の歌詞と何字違うか・要確認の理由）。**Enter で採用**（その区間の確定歌詞になる。Ctrl+Z で戻せる）、**ダブルクリックで直して採用**、**Esc で閉じる**。候補のままでは歌詞は変わらない。聞き取っている間はその区間の上に進み具合が出て、Esc で取り消せる。キーはショートカットの設定（グループ「歌詞」）で割り当てられる。
   - 初めて使うときだけ、モデルの大きさ（3.09 GB）・保存先（`%LOCALAPPDATA%\Gliss\models\asr`）・ライセンス（MIT）を確認するダイアログが出て、ダウンロードする（進み具合を表示。Esc で取り消すと途中のファイルは消す）。
   - エンジンの Python に faster-whisper が無いと「聞き取る」は無効（理由をツールチップに）。ソースから動かしているときは `uv pip install --python .venv\Scripts\python.exe faster-whisper`（engine の extras `asr`）で入れる（配布版では、聞き取りはまだ使えない。今後、画面から入れられるようにする予定。[development.md](development.md)）。GPU（CUDA）で速く聞き取るには Windows では `nvidia-cublas-cu12` も（extras `asr-cuda`）。無ければ CPU で動くが遅い（音声 10 秒あたり約 29 秒。GPU は約 1 秒）ので、ステータス行に出す。叫び・繰り返しは誤りが多い。AI からは MCP の `transcribe`（[MCP.md](../engine/docs/MCP.md) §1-1）。
5. **ノートの見た目**: ノートごとに、**ノートの平均の音程**（音量で重みを付け、無声と子音は除く。エンジンの `band_midi`）に置いた**水平な帯**（太さ＝音量の包絡。Melodyne の blob と同じ見せ方）。ピッチの揺れは細い線で重ねる（しゃくり・ビブラートで線が帯の外に出るのはそのまま）。ガイドも同じ形でグレー。枠は描かず、ノートの区切りは帯の両端を細めて見せる。選択中は濃く、ホバー中はやや濃く。**歌詞がある区間では、帯の中の子音の区間を同じ色相のまま彩度だけ落とす**（選択・ホバーの濃さは子音にも同じ比。歌詞が無い区間は区別しない）。息・囁き・無声の子音は、音のある部分を近い側のノートの高さに薄く表示する。分割後の短い区間にも操作用の細い帯を残す。無音は音程線のない細い帯で表示する。いずれもピッチ編集の対象外。
6. **編集**: blob の中央を上下にドラッグでピッチ（連続値）、左右にドラッグでノートの移動（最初の 4 px の向きで決まる）。blob の端を左右にドラッグで長さ（つかめるのは端から内側 8 px・外側 4 px（隣との隙間の半分まで。短いノートは幅の 1/3 まで）、縦は帯の中心から ±10 px。乗ると端に明るい縦線とカーソル ↔）。音素境界（blob の中の薄い縦線）を左右にドラッグで子音｜母音の境目。空白か歌詞レーンをドラッグで範囲選択、Shift+クリックで追加。右クリック（下の「右クリックのメニュー」）の「ガイドに合わせる…」（G。ピッチ・タイミングのスライダー。開いている間は音程の対応先のガイドノートだけ濃く出る。**「線の形もガイドに合わせる」は既定 ON**。発音の頭どうしを対応させ、間は比例時間で写したガイド F0 へ有声フレームごとに近づける。強さは Hz 単位で線形にかける（例: 100 Hz から 200 Hz へ 50% なら 150 Hz）。無声・対応のない区間は変えず、境目はなだらかにつなぐ。OFF は従来のノート平均音程を一定量ずらす方式。タイミングは発音の頭を、画面に描いたガイドの頭へ揃える。対応の決まらない頭は動かさない。確かな頭の組を基準点にして、その間のノート（発音の頭の無い音程の変わり目など）は前後の基準点に合わせて比例で動かす（同じフレーズで、基準点の間が 1 秒以内。基準点の無い所は動かさない）。[guide-timing.md](guide-timing.md)・[guide-coverage.md](guide-coverage.md)）と「オリジナルに戻す」。
   - **ガイドとの対応の表示**（issue #53）: 「ガイドに合わせる」を開いている間だけ、選んだノート（選択が無ければ全体）について、ガイドと確かに対応するノートはテイクの頭とガイドの頭を細い灰色線で結ぶ（1 対多は組の頭どうし・尻どうしの 2 本で範囲）。確かな対応の無いノートには灰色の破線の丸。ノートにポインタを乗せると「音程だけ対応／タイミングも対応（基準点・補間）／目標に届く」と、対応が無い理由が出る。縮小すると間引く。ステータス行に対応の数が出て、確かな頭の組が 1 つも無いガイド（別の演奏など）では「このガイドとはタイミングを合わせられない」。
   - **補正の色**: 帯はタイミング、細い線はピッチの補正を示す。子音・息・無音の帯にもタイミングの補正色が付く。自動補正は元からの移動量に応じて黄から赤へ連続的に変わり、手動補正は白。両方をかけたときは最後にかけた方の色。度合い 1 の基準はタイミング 80 ms、ピッチ 100 セント（そのノートで最大の絶対移動量）。選択した区間の長さを変えていれば、帯の上に元の長さを細いグレーの線と両端の短い縦線で示す。ガイドは濃いグレー、伴奏は薄いグレー。
   - **処理中**（issue #63）: 出し方は 2 通り。
     - **続けられる処理**（編集の反映・再生の音作り・トラックの切り替え・聞き取り）: 0.3 秒を超えたら、ヘッダー下端の細い線と矢印・砂時計のカーソル。操作は続けられる。トラックの切り替え・聞き取りは、そのクリップ・区間の上にも細い線。描画データの読み直し・一覧・準備の状態の確認のような裏方の呼び出しでは線を出さない。
     - **待たせる処理**（開く・新規・書き出し・聞き取りのモデルの取得、準備が終わる前に開いたトラック、Ctrl+Z・ガイドの指定・トラックを外す・保存・外部の変更・歌詞の入力で解析が残ったとき）: 始まった瞬間から画面全体に覆いを掛け、後ろのクリック・ドラッグ・キー・メニューを受けない。0.2 秒を超えたら覆いを暗くして、中央のポップアップに 何をしているか・対象（ファイル名）・段階・進み具合（% か、分からなければ流れる線）・経過の秒・「終わるまで編集できません」を出す。覆いの上をクリックするとポップアップが小さく揺れる。一度出したら 0.6 秒は残す（終わっていれば「終わった」と出し、その間の操作は通す）。準備済みなら解析はすぐ返るので、ポップアップも覆いも出ない。2 つ重なったら後から始まったものを出す。
     - 取り消せるときだけ「取り消し（Esc）」を出す（開く・書き出し・モデルの取得・準備を待っているトラック）。準備を待っているトラックを取り消すと、前のトラックと表示範囲に戻る（そのトラックの準備は裏で続く）。中断できない段階では「取り消し」を出さない。
     - 取り消しを出さない待ち（Ctrl+Z・ガイドの指定・トラックを外す・保存・外部の変更・歌詞の後の解析）も、15 秒を超えたら「待つのをやめる（Esc）」を出す（別のエンジンが準備を握ったまま・準備が進まないときに抜けられるように。15 秒は Claude Code からの同期の待ちの上限と同じ）。やめると、そのトラックの下の表示を空にして「準備中。終わったら表示する（トラックを選ぶと、もう一度待つ）」と出し、裏の準備が終わったら自動で描き直す。空の間の編集（Ctrl+Z など）は「準備中。少し待ってからもう一度」で断る。準備が続いていなければ「待つのをやめた。トラックを選ぶと、もう一度解析する」。
   - **子音・息・無音の幅とタイミング**（issues #35・#44）: 子音・息・無音の帯も、矢印のとき**帯を横にドラッグで移動**、**区間の端（乗ると明るい縦線）を横にドラッグで幅**。音程のあるノートと同じく、ドラッグ中の見た目 = 離した後、接していれば隣のノートが伸び縮み（接続）、**Alt+ドラッグで切り離し**（隣は動かず隙間が増減）・隣にぶつかる所で吸着、時間スナップ、Ctrl+Z で戻る（取り消しの名前は「ノートの長さ」「ノートの移動」）。**上下には動かない**（音程が無いので、動かし始めの向きによらず横の移動だけ）。操作した区間を選択する。挟んでいる音程のあるノートの境目を切り離していれば、子音の両側も切り離し（次のノートの頭に付いた短い子音は次のノートとつながる）。MCP は `move_note` / `stretch(note_id)` / `plan_edit` に子音・息・無音の区間の id（[MCP.md](../engine/docs/MCP.md) §2-0）。
   - **フェード**: ノートに乗ると帯の上の両端に小さな四角（DAW のクリップフェードと同じ位置と形）。**内側へドラッグでフェードイン／アウトの長さ**（ドラッグ中はツールチップに ms）。帯はフェードの分だけ細くなる（ドラッグ中の見た目 = 聞こえる音量）。変えるのは**音量だけ**で、ピッチのなだらかさとは別。形は 1 種類（等パワー）。接続された境目にも付けられ、隣のノートは変えない。ノートの長さを変えてもフェードの秒は保ち、ノートより長くはならない。再生・書き出しに反映（フェードの外は元のサンプルのまま）、Ctrl+Z で戻る。右クリック「フェードを消す」（フェードのあるノートのときだけ）。オリジナルに戻すでも外れる。MCP は `set_fade`。
   - **グリッドとスナップ**（v3 §4）: ピアノロールに時間グリッド（テンポがあれば小節・拍、無ければ秒）の縦線、音程グリッドは半音の行（鍵盤の行）。ヘッダーの**時間スナップ（N。縦線から右へ横線のアイコン）**、隣の**音程スナップ（Shift+N）**。**既定はどちらもオフ**、**Shift を押している間は解除**（Studio One と同じ）。時間スナップはノートの端・移動・はさみの切る位置・トラックビューのクリップの位置をグリッドに寄せる。音程スナップはピッチのドラッグで**帯の高さ（ノートの平均の音程）を半音に**合わせ（Melodyne と同じ）、ドラッグ中だけ「G4 ±0¢」と出す。
     - **グリッドの細かさ**: スナップのアイコンの隣のプルダウン（Studio One のクオンタイズ値と同じ位置付け）。小節・拍のときは 自動／1/1〜1/32／1/2〜1/16 の 3 連符、分:秒のときは 自動／1〜0.01 秒。**トラックビューとエディターで共通**（プルダウンは 1 つ。自動ならそれぞれのズームで線が詰まりすぎない刻み = 上は粗く・下は細かく）。スナップのオン・オフと細かさはユーザー設定に残し、取り消しの履歴には入れない。
     - **テンポ**: ヘッダーの時刻の右に「120 BPM 4/4」を常に出す（Studio One のトランスポートと同じ）。**数字をクリックで入力**、**上下にドラッグ・ホイールで ±1**（Shift で ±0.1）。拍子もクリックで入力・ホイールで分子を ±1。テンポが無いうちは「— BPM」と薄く出し、そこから入れられる。**伴奏などの WAV の iXML にある PreSonus のテンポマップ（Fender Studio Pro のミックスダウン・バウンス）を自動で読み**、そのときだけ数字の前に小さく「iXML」（ツールチップに読んだファイル。手で変えると消える）。1 小節目は bext の TimeReference から（ソングの 0:00 = 1 小節目とみなす）。途中でテンポが変わる曲も、グリッドはファイルの頭のテンポ 1 つ。ルーラーの右クリック「テンポと拍子…」で 1 小節目の位置も入れられ、「表示: 小節・拍／分:秒」でルーラーの読み方を切り替える。**テンポの変更は取り消しの履歴に入る**（ドラッグ・続けたホイールは 1 回にまとめる）。MCP は `set_tempo`。
   - **元に戻す**（Ctrl+Z）/ **やり直す**（Ctrl+Shift+Z・Ctrl+Y）: **曲に保存されるものを変えた操作はすべて**戻せる（ノートの編集・フェード・歌詞・音素の境界・トラックの追加・外す・位置・名前・種類・並び順・ガイドの指定・テンポと拍子）。履歴は**トラックをまたいで 1 曲で 1 本**で、別のトラックの操作を戻すとそのトラックに切り替わる。ミュート／ソロ・音量・パン・表示・選択・編集対象の切り替えは戻さない（DAW と同じ）。次に戻す操作はボタンのツールチップと **編集** メニューに「元に戻す: ノートの長さ」のように出て、戻した直後にステータス行に 1 回「元に戻した: …」。**Claude Code の編集も同じ履歴に入る**（MCP の `undo` / `redo` も同じ履歴。[MCP.md](../engine/docs/MCP.md) §2-9）。履歴はセッション（`session.json`）に残るので、開き直しても戻せる。
   - **順番待ち**: 編集はすべて順番に当たる（前の編集をエンジンが当てている間に離した操作も捨てない）。**まだ当たっていない操作は Ctrl+Z で列から外すだけ**（画面からすぐ消える）。書き出し・開き直しは、順番待ちの編集が当たってから行う（「前の編集を当ててから書き出します」）。
   - **ツール**（ヘッダーのアイコン、キー **1 / 2 / 3 / 4**）: 矢印（上の操作）・**鉛筆**（ピアノロールをドラッグしてピッチを描く。両端は元の曲線へなだらかにつながる。無声には描けない。上から描き直すと、すっぽり覆われた前の線は外れる）・**はさみ**（ノート・子音・息・無音の帯をクリックで分割、音素境界の近くは吸着・Alt で吸着なし。同じ種類の境目をダブルクリックで結合）・**ミュート**（承認済み（2026-10-03）。ノート・子音・息の帯をクリックで無音にする／無音のノートをクリックで戻す。押したまま横になぞると、通ったノートを**最初に押したノートと同じ向き**にそろえる。離したときに 1 つの編集として当たり、Ctrl+Z 1 回で戻る。戻すのは無音だけで、ピッチ・タイミング・フェードの編集は残る。カーソルは「スピーカーに ×」）。分割後も幅・タイミングを編集でき、取り消せる。鍵盤とルーラーの上はどのツールでも矢印のカーソル。
   - **ノートの変わり目は自動でなだらか**（移動量に段差がある所 = ピッチを動かしたノートと隣の境目・結合した元の境目などを、原音の移り変わりの長さで曲線にする）。右クリック →「つなぎのなだらかさ…」のスライダーで調整（左端 = 段差、中央 = 自動、右端 = ゆっくり）。切り離しの境目には効かない。値は時刻で持つので、分割・結合しても線と音は変わらない。
   - **タイミングの編集は後ろをずらさない**（Melodyne と同じ）。隣り合うノートの境目は**接続**（くっついている＝境目を共有して動く）か**切り離し**（隙間がある＝自分だけ動いて隙間が増減する）。**Alt+ドラッグ**で接続を切って自分だけ動かす。切り離した端を隣にぶつかるまで伸ばすと吸着して接続に戻る。**接続の表示**は、境目に近づいたとき・ノートを選んだとき・ドラッグ中だけ、その境目に出る（接続 = 塗りの点＋線、切り離し = 両端に白抜きの点。線の曲がる幅 = なだらかさ）。Alt を押すと線が破線になり、ここで切れることを予告する。切り離し・吸着でなだらかさが消える／現れるのも、ドラッグ中の曲線に出る。歌詞があれば伸び縮みは母音だけで、子音の長さは保つ。
   - **右クリックのメニュー**（右クリックした所の対象だけ。1 つ 3〜7 項目、キーは右に表記）:

     | 右クリックした所 | 項目 |
     |---|---|
     | ノート | ガイドに合わせる…（G）／半音に合わせる（Q）／ここで分ける（Alt+X）／なだらかさ…（T）／フェードを消す（フェードのあるときだけ）／オリジナルに戻す／無音にする（Del）／無音を戻す（無音のノートのときだけ） |
     | 複数選択 | 上と同じ。「ここで分ける」の代わりに 結合（Ctrl+J。隣り合って接しているときだけ） |
     | ノートの境目 | 結合（Ctrl+J）／切り離す（接続のとき）・つなぐ（切り離しのとき。隙間があれば前のノートを伸ばしてつなぐ）／なだらかさ…（T） |
     | 空白（ピアノロール） | すべて選択（Ctrl+A）／時間スナップ（N）／音程スナップ（Shift+N）／全体を表示。スナップはオンのときチェック |
     | 歌詞レーン | 歌詞を入力…・編集…（ダブルクリック）／この区間の歌詞を消す／歌詞を読み込む… |
     | 音素（レーンの下段） | 子音｜母音の境目を元に戻す（その音素の境目を動かしたときだけ）／歌詞を編集… |
     | トラック見出し | 名前を変える（F2）／このトラックをガイドにする（外す）／元の位置に戻す／伴奏として扱う／トラックを外す |
     | クリップ | ここを下に表示／元の位置に戻す／トラックを外す |
     | ルーラー（上下とも） | ループを解除／テンポと拍子…／表示: 小節・拍・分:秒（小節・拍はテンポがあるときだけ） |

     未選択のノートを右クリックすると、そのノートを選んでから出す。**無音にする**は長さ・位置を変えずに音だけを消す（帯が点線の輪郭と薄い塗りになり、ピッチの線は灰色になる。トラックビューの編集中のトラックにも、無音の区間が点線で出る。承認済み（2026-10-03）。戻すのは無音を戻す・Ctrl+Z・オリジナルに戻す）。**無音を戻す**は無音のノートを選んだときだけ出て、無音だけを外す（ピッチ等の編集は残る。承認済み（2026-10-03））。**半音に合わせる**は帯の高さ（ノートの平均の音程）をいちばん近い半音へ。どれも 1 回の Ctrl+Z で戻る。
   - **キーボードショートカットとホイール**（既定。**編集 > ショートカット（キー・ホイール）…**（Ctrl+,）で変えられる）:

     | グループ | コマンドとキー |
     |---|---|
     | 再生・ツール | 再生／停止 Space・メインツール 1・鉛筆 2・はさみ 3・ミュート 4・つかんだノートを鳴らす（なし。オン・オフ） |
     | 編集 | 元に戻す Ctrl+Z・やり直す Ctrl+Shift+Z / Ctrl+Y・すべて選択 Ctrl+A・ショートカット（キー・ホイール）… Ctrl+,・テンポを入力（なし） |
     | ノート | ガイドに合わせる… G・半音に合わせる Q・ここで分ける Alt+X（再生位置で。選んだノートの上）・結合 Ctrl+J・なだらかさ… T・無音にする Del・無音を戻す（なし）・オリジナルに戻す・フェードを消す（なし） |
     | 表示 | 再生位置に追従 F・時間スナップ N・音程スナップ Shift+N・ガイドを重ねて表示・全体を表示・ズームを戻す（なし） |
     | トラック | トラックの名前を変える F2 |
     | ファイル | 新規プロジェクト Ctrl+N・開く… Ctrl+O・保存 Ctrl+S・名前を付けて保存… Ctrl+Shift+S・トラックを追加… Ctrl+Shift+O・書き出し Ctrl+E・書き出し先を選んで書き出し… Ctrl+Shift+E・ガイドを開く…・歌詞を読み込む（テキスト / SVP・MIDI）…（なし） |
     | ホイール | 縦ズーム（音程の幅・トラックの高さ）Ctrl+ホイール・横ズーム（時間の幅）Ctrl+Shift+ホイール・縦スクロール（音程・トラック）ホイール・横スクロール（時間）Shift+ホイール（Studio One と同じ） |

     Esc はメニュー・ポップアップを閉じる／選択を外す（固定）。Alt+ドラッグ・Shift（スナップの解除・細かく）は変えられない。
     **設定画面**: 上の欄でコマンド名かキーで検索。行をダブルクリック → キーを押すと割り当て（Esc でやめる）。ほかのコマンドと重なると、その行の下に「Q は「半音に合わせる」に割り当て済み　置き換える／やめる」。変えた行は右に「既定: …」と ↺（既定に戻す）、× でキーを外す、下に「すべて既定に戻す」。**ホイールの行**（いちばん下）はダブルクリック → 修飾キー（Ctrl・Shift・Alt）を押しながらホイールを回すと割り当て（キーは受け付けない。重なりはキーと同じ）。右クリックのメニュー・メニューバー・ツールチップの表記も設定に従う。設定はユーザー設定（userData の `state.json` の `keys`）に保存し、取り消しの履歴には入れない。
     メニューバーは ファイル／編集／ノート／表示／ヘルプ（Gliss について）。名前・キーは右クリックのメニューと同じコマンドの表から作る。
     **ウィンドウはタイトルバー一体型**: Windows のタイトルバー・メニューバーは無く、上端の 1 本のバー（本体と同じ色）に ロゴ・メニューバー・中央にプロジェクトの名前、右端に OS の最小化／最大化／閉じる（最大化ボタンに乗るとスナップレイアウト）。バーの空いた所をドラッグでウィンドウを動かし、ダブルクリックで最大化／元に戻す。メニューは Windows のメニューバーと同じくキーで操作できる: **Alt**（か F10）だけを押して離すとメニューバーへ、←→ で選び、↓・Enter で開く、↑↓ で項目、→ で下の段、Enter で実行、Esc で 1 段ずつ閉じる（Alt を Alt+X・Alt+ドラッグなどに使ったときは行かない）。中身は Electron のメニューをそのまま写して描く。
7. **再生**: Space か ▷。タイムスケールのドラッグでループ区間、ダブルクリックで発声区間へジャンプ。
   **再生位置に追従**（issue #40。オートスクロール。ヘッダーの →| のアイコン・**F**・表示メニュー。Studio One と同じ）: オンなら再生中に再生位置が表示範囲を出たら画面を送る（エディターと、ズームしている上のトラックビュー）。オフなら送らない。既定はオン。ユーザー設定に残し、取り消しの履歴には入れない。
   **つかんだノートのプレビュー音**（Melodyne と同じ）: ノート（端）をつかんでいる間、そのノートをループで鳴らす。ピッチのドラッグ中は今の高さで作り直して追従する（エンジンの `render_audition`。1 ノート 10 ms 前後。作り直しは 1 本ずつ・間引く）。移動・端のドラッグでもつかんだノートを鳴らす（高さは今のまま）。離したら止める。再生中は鳴らさない。**編集 > つかんだノートを鳴らす** で切り替え（既定はオン。ユーザー設定に保存）。
8. **表示（ホイール。既定は Studio One と同じ。上の設定画面で変えられる）**: **ホイール＝縦スクロール（音程）**、**Shift+ホイール＝横スクロール**、**Ctrl+ホイール＝縦ズーム**（ポインタの下の音程を中心に 6〜36 半音。タッチパッドのピンチもこれ）、**Ctrl+Shift+ホイール＝横ズーム**（ポインタの下の時刻を中心に）。タッチパッドの横スクロール（横の量）は割り当てによらず横スクロール。縦スクロールはデータの音域の上下 1 オクターブまで。**表示 > ズームを戻す** で縦・横・トラックの高さ・上の横の表示範囲を開いたときの表示に。上のトラックビューでは縦ズーム = トラックの高さ、縦スクロール = トラックのスクロール、横ズーム・横スクロール = 上の時間の表示範囲（下とは別。上の 3）。縦の表示とトラックの高さも前回の表示範囲と一緒に覚える（同じテイクのとき）。
9. **書き出し**（編集中のトラック）: **ファイル > 書き出し**（Ctrl+E）。ダイアログを出さず、**元ファイルの隣に `<名前>_ve.wav`**（既にあれば上書きせず `_ve(2)`、`(3)` …）。元と同じ形式・長さ・開始位置の WAV で、編集した区間だけ差し替わり、他はサンプル単位で元のまま。**元の WAV の BWF（`bext` の TimeReference＝DAW 上の位置）と `iXML` も書き写す**ので、DAW に戻して「元の位置へ」で揃う（次の節）。場所を選ぶときは **ファイル > 書き出し先を選んで書き出し…**（Ctrl+Shift+E）。**トラックの位置をずらしていれば、中身・長さはそのままで TimeReference をその量だけ動かす**（DAW で「元の位置へ」→ ずらした位置に来る。元に bext が無くても足す）。DAW に効くのは書き出すテイクの位置だけ（伴奏・ガイドをずらしても DAW 側は変わらない）。DAW で途中から録ったテイク（bext の位置が 0 でない）はトラックビューではファイルの頭を 0 に置くので、伴奏に合わせるためにずらして書き出すと DAW 上で二重にずれる（書き出しで警告が出る。`docs/track-view.md` §4）。

## 2. DAW との往復

このツールはスタンドアロン。DAW の録音ファイル（WAV）をそのまま開いて直し、書き出した `_ve.wav` を DAW に戻す。
書き出しは**元と同じ長さ・同じ開始位置**で、元の WAV に `bext`（BWF のタイムスタンプ）があれば同じ値を入れる。

### Fender Studio Pro（旧 Studio One）

Studio One / Fender Studio Pro が書く WAV には `bext` が入っている（手元のソングのフォルダを 2026-09-23 に調べた。`JUNK, fmt , fact, bext, acid, data` の並び、bext は v1 で説明・作成者は空）。

| ファイル | TimeReference（`bext`） |
|---|---|
| 録音（`<ソング>\Media\` の `vo.wav`・`vo(2).wav` …） | **録音を始めたソング上の位置**（サンプル数。例: 44.1 kHz で 4,771,683 = 108.2 秒） |
| バウンス（`Bounces\`）・ミックスダウン（`Mixdown\`） | 書き出した範囲の開始位置（曲頭からなら 0） |
| 読み込んだ素材を Studio One が変換したもの（`Media\`） | 0 |
| 他のソフトで作った素材 | bext が無いものが多い（Media の WAV 496 個のうち約半数）。あっても入っているのはそのソフトの値 |

iXML はミックスダウン・バウンスの一部にだけあり、中身は PreSonus のテンポマップ（`<PRESONUS><TEMPO_MAP>`）。このツールはこれを伴奏のトラックから読んで、グリッドのテンポにする（`TEMPO_SEGMENT_OFFSET` = ファイルの頭からのサンプル数、`TEMPO_SEGMENT_VALUE` = 1 拍の秒数。拍子は入っていない。2026-09-25 に 14 本で確認）。

手順（テイクの録音ファイルを直して、元の位置に戻す）。**手順 1 のプールの「エクスプローラーで表示」と手順 4 の「元の位置」のボタンは、まだ実機で確かめていない**（前者は推測、後者は PreSonus の旧マニュアルの記述による。メニュー名は版・言語で違うことがある）:

1. **元の WAV の場所を開く**: トラックのイベントを選び、**ブラウザの「プール」**（ソングで使っているファイルの一覧）で該当ファイルを右クリック →**「エクスプローラーで表示」**（メニュー名は版で違うことがある。見つからなければソングのフォルダの `Media` を直接開く）。録音なら `<ソングのフォルダ>\Media\<トラック名>.wav`。
2. **このツールで開く**: エクスプローラからその WAV をこのツールのウィンドウに**ドラッグ＆ドロップ**（ガイドは Shift+ドロップ）。
3. 編集して **Ctrl+E**。同じ `Media` フォルダに `<名前>_ve.wav` ができる（ステータス行に「DAW 上の位置 1:48.201」のように元の位置が出る）。
4. **DAW に戻す**: `_ve.wav` をエクスプローラから元のトラック（か新しいトラック）にドロップ → イベントを選び、**イベントのインスペクター（F4）の「元の位置（Original Position）」の右のボタン**を押す。タイムスタンプの位置（＝元の録音の頭）に移る。見つからなければ、元のイベントの頭（トリムしていればトリムを戻した位置＝ファイルの頭）にスナップさせて置く。
5. 元のイベントをミュートして聴き比べ、良ければ差し替える。元の WAV は書き換えていない。

注意:

- 「元の位置」は**録音したときの位置**。録音の後で元のイベントを動かしていたら、`_ve.wav` は動かす前の位置に来る（動かしたぶんは手で合わせる）。イベントの頭をトリムしていても、`_ve.wav` はファイル全体なので「元の位置」で元のファイルと同じ位置に来る（トリムはやり直す）。
- 読み込んだ素材（TimeReference が 0）は「元の位置」が曲頭になる。その場合は元のイベントの頭（ファイルの頭）にスナップさせて置く。
- ソングのサンプルレートと WAV のサンプルレートが違うと、Studio One が変換したファイルを `Media` に作ることがある。そのときは変換後のファイル（プールに出ているもの）を開く。
- ステータス行の「DAW 上の位置」は、元の WAV に `bext` があったとき（か、トラックの位置をずらしたとき）だけ出る。トラックの位置をずらしていれば、手順 3・4 の「元の位置」は**ずらした後の位置**になる。
- `acid` チャンク（テンポ情報）は書き写さない。`_ve.wav` をテンポに追従させない（ストレッチしない）ようにしておくこと。

### Reaper

**Preferences > External Editors** に `Gliss.exe` を登録する（下の「外部エディタとして登録する」）。アイテムを右クリック → **Open items in primary external editor** でこのツールが開く（**copies の付かない方**。「Open copies of items …」はアイテムを切り出した複製を開くので、元の位置の情報が変わる）。書き出した `_ve.wav` をトラックにドロップし、アクション **Item: Move to source preferred position (used by BWF)** で元の位置に揃う。
そのファイルを新しいプロジェクトのテイクとして開く（そのテイクを issue #33 より前に開いていれば、そのときの `projects\…` が開く）。閉じるときに「保存しますか」と出るので、編集を残すなら `.gliss` に保存する（保存しなくても、書き出した `_ve.wav` は残る）。

### ほかの DAW

書き出しの約束（元と同じ長さ・開始位置、BWF の `bext` を保つ）は DAW を問わない。BWF のタイムスタンプで置き直す機能（Cubase の「元の位置に移動」、Pro Tools の Spot など）か、元のファイルの頭にスナップして置けば揃う。

### 外部エディタとして登録する

`Gliss.exe <WAV>` で、その WAV（`.wav`・`.flac`・`.aiff`）を新しいプロジェクトのテイクとして開く（`--take <WAV>` と同じ）。DAW の外部エディタには `Gliss.exe`（既定のインストール先は `%LOCALAPPDATA%\Programs\Gliss\Gliss.exe`）をそのまま登録する。
Gliss を開いたままもう一度呼ぶと、別のウィンドウ（別のプロセス）で開く。

ソースから動かしているときは `app\gliss.cmd`（同じ働き。旧称の `app\vocal-editor.cmd` も残してある）を登録する。

## 3. AI（Claude Code など）から使う

**Gliss の ヘルプ > AI とつなぐ…** で登録する:

- **Claude Code [追加]**: Gliss が `claude mcp add-json gliss … --scope user` を実行する（ユーザー全体。どのフォルダーで Claude Code を起動しても使える）
- **Claude Desktop [追加]**: `%APPDATA%\Claude\claude_desktop_config.json` に `gliss` を足す（ほかの設定はそのまま・書く前にバックアップ）。足したら Claude Desktop を再起動する
- **その他 [設定をコピー]**: `mcpServers` の JSON をクリップボードへ
- **AI に許可**: 編集（既定オン）・保存・書き出し（既定オフ。聞き取り用のモデルの取得 `prepare_asr_model` もこちら。聞き取る `transcribe` は許可なし）。許していない操作は AI に「Gliss の設定で許可できる」と返る

画面で曲を開いたまま、Claude Code に「Gliss で今開いている曲の…」と頼むと、AI は `load_project()`（引数なし）で**画面の曲と編集中のトラック**を開いて編集し、画面に即反映される（逆も同じ）。ノート・範囲を選んで右クリックの **AI に頼む** を押すと、「Gliss（gliss）で、今開いている曲の take1 トラックの n004〜n009（1:24.30〜1:26.10、6 ノート）について:」の形の書き出しがクリップボードに入るので、続きを書いて貼る。AI の操作は取り消しの履歴（「元に戻す: AI · ピッチ」）とノートの縁の色で見分けられる。仕組み（許可の対象のツール・`bridge.json`）は [MCP.md](../engine/docs/MCP.md) §4-1。

```
Gliss で今開いている曲の、ずれの大きいノートを一覧して、70% でガイドに寄せてから測り直して、図で見せて
```

手で設定するときは、ヘルプ > AI とつなぐ… の「設定をコピー」の JSON を使う（配布版はインストール先のエンジン exe を指す）。ソースから動かすときの設定は [development.md](development.md)。

ツール名は `mcp__gliss__<ツール>`（旧称のときは `mcp__vocal__…`。Claude Code の許可の設定に旧い名前を書いていたら直す）。

```
C:\曲\take.wav をテイク、C:\曲\guide.wav をガイドとして開いて、
歌詞「さくらさくら やよいのそらは」を付けて、ずれの大きいノートを一覧して、
70% でガイドに寄せてから測り直して、図で見せて
```

ファイルの途中から切り出したクリップを編集するときは `open_project(take_path, offset_sec=…, length_sec=…)`（プロジェクトの秒はクリップの頭が 0）。区間の PCM を長さを変えずに取るのは `render_region`（DAW 連携向け）。詳細は [daw-stage0.md](daw-stage0.md)。

トラック（複数テイク・ガイド・伴奏）は `list_tracks` / `select_track` / `add_track` / `remove_track` / `set_track`（位置 `offset_sec`・ミュート／ソロ・音量 `gain_db`・パン `pan`）/ `set_guide_track`、曲のテンポと拍子は `set_tempo`、ノートのフェードは `set_fade`。既存の編集ツールは編集対象のトラック（`select_track`）に効く（[MCP.md](../engine/docs/MCP.md) §3-2）。

プロジェクトのファイルは `new_project` / `load_project`（引数なしで画面の曲。`path` で `.gliss`・旧形式の `projects\…`・音声）/ `save_project`（`path` で名前を付けて保存）/ `project_status`（未保存か）/ `close_project`（[MCP.md](../engine/docs/MCP.md) §3-3）。画面を開いていないときは `.gliss` のパスを渡して開く（画面と同じ作業場所を使う）。AI からの保存は「AI に許可: 保存・書き出し」がオンのときだけ:

```
C:\曲\うた.gliss を開いて、take のトラックで、ずれの大きいノートを 70% でガイドに寄せて保存して
```

ツールの流れ: `open_project` → `analyze_take` → `set_lyrics` → `list_deviations` → `correct_to_guide` / `shift_pitch` / `set_pitch_curve`（`mode="draw"` で鉛筆）/ `set_transition` / `split_note` / `merge_notes` / `move_boundary` / `stretch` / `move_note` → `remeasure` / `render_view`（PNG のパス）/ `render_preview`（WAV のパス）→ `export_wav`。タイミングの編集は画面と同じく後ろをずらさない（接続の状態は `list_connections` / `set_connection`）。

`correct_to_guide` の `match_pitch_shape` は既定 `true`。`false` にするとノートの平均音程をガイドへ寄せ、元の揺れの形を保つ。画面のチェックボックスと同じ設定。
