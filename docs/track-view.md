## 1. 編集モデル: 複数トラックのセッションと MCP ツール

### 形

`engine/vocal_engine/project/session.py`（セッション）と `engine/vocal_engine/mcp_tracks.py`（MCP ツール 8 個）。

| もの | 中身 |
|---|---|
| セッション（`session.json`） | 1 曲ぶんのトラックの並び・ガイドの指定（1 本）・最後に選んだトラック |
| トラック | 1 つの音声ファイル（かその一部）。`kind`（`vocal` = ボーカルのテイク／`inst` = 伴奏。聴くだけ）・名前・**タイムライン上の位置 `offset_sec`**・ミュート／ソロ・**音量 `gain_db`・パン `pan`**（再生だけに効く。§3.1） |
| ボーカルのトラックの編集 | **トラックごとのプロジェクト**（今までの `Project` = 1 テイク＋ガイドの形そのまま。編集リスト・取り消し履歴・歌詞・解析のキャッシュ） |

- **置き場**: 最初に開いたテイクのプロジェクトのディレクトリ（今までと同じ `projects/<名前>-<sha8>/`）に `session.json`。
  他のボーカルのトラックのプロジェクトはその下の `tracks/<名前>-<sha8>/`（セッションごとに独立。
  同じファイルを別の曲で使っても編集が混ざらない。テストの置き場の分離にもなる）。
- **既存の MCP ツールは「編集対象のトラック」に効く**（`shift_pitch` などは何も変えていない）。編集対象は
  `select_track` で切り替える。**どのトラックを編集しているかはプロセスごと**（画面と Claude Code が別のトラックを
  同時に編集できる）。`session.json` の `current` は「最後に選んだトラック」（開き直したときに戻す）だけ。
- **ガイドの重ね方**: 編集対象のテイクのプロジェクトに、ガイドのトラックを**テイクの頭のタイムライン上の位置から**
  切り出したクリップを渡す（`media.Clip`。前が足りなければ無音で詰める＝`pad`。§4）。位置が同じならファイル
  全体をそのまま渡すので、**既存のプロジェクトはガイドの解析・歌詞・編集リストがそのまま**使える。
  ガイドのトラック自身を編集対象にしたときは重ねない（プロジェクトからガイドを外す `Project.clear_guide`）。
- **後方互換**: `session.json` の無いプロジェクト（issue #7 より前。1 テイク＋ガイド）を開くと、テイクとガイドの 2 トラックの
  セッションを作ってガイドのトラックをガイドに指定する。`open_project(take, guide)` は今までどおり呼べて
  （返り値に `session` が増えただけ）、`guide` を渡すとそのファイルのトラック（無ければ足す）をガイドに指定する。
  サンプル列（`media.Samples`。DAW 連携の API）で開いたときはセッションを作らない（今までどおり）。
  ガイドの音声が一時的に見つからないとき（外付け・同期待ち）は、プロジェクトのガイドを外さずに残し、見つかったら
  ガイドのトラックにする。
- **外部との同時編集**: `session.json` も `project.json` と同じく、読む前にディスク上の変化を見て読み直す
  （last-writer-wins）。外部がガイド・位置を変えて編集対象のガイドが古くなったら `list_tracks` の
  `guide_stale` が true（画面はこれを見て開き直す）。壊れた `session.json` は退避して作り直し、新しい版は読まない。

### MCP ツール（`engine/docs/MCP.md` §3-2）

| ツール | 何をするか |
|---|---|
| `list_tracks` | 一覧（位置・長さ・ミュート／ソロ・音量・パン・聞こえるか・ガイド・編集対象・`guide_stale`） |
| `select_track` | 編集対象を切り替える（返り値は `open_project` と同じ形。伴奏は選べない） |
| `add_track` | ファイルを足す（`kind` 省略時はファイル名から推す。`guide` / `select` も一緒に） |
| `remove_track` | 外す（ファイル・編集は消さない。ボーカルが 0 本になる外し方はできない） |
| `set_track` | 名前・種類・ミュート／ソロ・**音量・パン**（§3.1）・**位置**（§4） |
| `set_guide_track` | 共通のガイドを 1 本指定（null で外す） |
| `set_track_guide` | トラックごとのガイドを指定（`guide_track_id` 省略で共通のガイドに戻す。`guide_id` / `effective_guide_id` / `is_guide` が一覧に付く） |
| `track_overview` | 画面向け: 全体の波形（20 ms ごとの \|振幅\| の最大、チャンネルごと）の JSON |
| `render_tracks` | 画面の再生向け: トラックごとの音のファイル（§2） |

`open_project` の中身（`mcp_server.py`）はセッションを開くように変えた（`session.open_session`）。
`export_wav` はトラックの位置を TimeReference に足す（§4）。他の既存ツールは変えていない。

## 2. 再生: 複数トラックのミックス、ミュート／ソロ、ガイドを聴く

- **全トラックを混ぜて鳴らす**（`app/renderer/audio.js`）。エンジンの `render_tracks` がトラックごとの音のファイルを
  返し、画面が Web Audio でタイムライン上の位置に置いて鳴らす。**ガイドのトラックも他と同じく鳴る**
  （テイクと重ねる・ソロで切り替える。決定コメントの「ガイドの音声を聴けるように」）。
  - 編集のあるボーカルのトラック: 編集を当てた音（`render_region` と同じ中身＝書き出しと同じ。長さ・チャンネルは
    元のまま）。`<トラックのプロジェクト>/renders/stem-<編集の版>.wav` に書き、**編集が変わるまで使い回す**
    （新しい 3 つだけ残す）。今までの `render_preview`（モノラル）から、書き出しと同じ音（ステレオならステレオ）になった。
  - 編集の無いトラック・伴奏: 元のファイルそのもの（コピーしない）。画面（Chromium）が読めない形式
    （AIFF など）とファイルの一部（クリップ）だけ、セッションの `mix/` に WAV を書く。
  - 画面の main は、`render_tracks` が返したファイルだけを読むのを許す（プロジェクトの外の元の WAV を読むため）。
- **ミュート／ソロはトラックごとの GainNode**。再生中に押してもその場で聞こえ方が変わる。規則は DAW と同じ
  （どれかがソロならソロのものだけ。ミュートはソロより強い）。値はエンジン（`set_track`）に残る。
  既定は全トラック鳴る（DAW と同じ。ガイドだけ既定でミュートにする、はしていない）。
  **音量・パン**も同じ GainNode（ミュート／ソロの 0／1 × 音量）と、その次の StereoPannerNode（パン）で当てる（§3.1）。
- **再生位置とループはタイムラインの秒**（上下で共通）。再生範囲はループがあればループ、無ければ再生位置から
  タイムラインの終わり（一番後ろのトラックの終わり）まで。ループは区間の終わりの 0.4 秒前に次の周回を
  AudioContext の時刻で予約するので、どのトラックも同じ時刻に頭へ戻る。
- 再生中に再生位置がピアノロールの表示範囲を出たら、ピアノロールを画面送りする（モックと同じ。上の白枠も追従）。停止中は送らない。再生中に利用者が表示範囲を動かしたら、再生位置が範囲に戻るか次の再生まで送らない（`app/renderer/follow.js`）。
- 下のピアノロールのタイミングの編集（区間の端・本体のドラッグ）は 1 つの規則: **接している隣とは境目を共有、離れていれば隙間が変わる、Alt で自分だけ**。音程のあるノート・子音・息は種類によらず同じ区間として扱う（`engine/vocal_engine/project/timing.py` の冒頭、[user-guide.md](user-guide.md)）。
- ピアノロールの中の秒（編集の秒）はトラックの頭が 0 のまま。目盛り・時計・再生位置・ループは
  **タイムラインの秒**で出す（トラックをずらしたら目盛りの数字がずれる）。

### 3.1 見出しの音量・パンと幅（承認済み（2026-10-03））

見出しを小さなミキサーにし、そのぶんの幅を変えられるようにした。見た目と操作は AsIs/ToBe のモックで承認済み。
実装は `app/renderer/tracks.js`（見出し・操作）・`mixer.js`（目盛りと表記。DOM に触れない）・`session.js`（`setMix`）・
`audio.js`（再生）・`index.html`（見た目）。

**見出しの 2 段**（1 段目 = 名前・準備の印・ガイド・M・S は今までどおり。2 段目 = 音量のスライダー・dB の数字・パンのノブ）

| もの | 決めたこと |
|---|---|
| 音量 | **−∞〜+6 dB**。スライダーは 3 乗に近い目盛り（線形の増幅率が `(位置 / 0.8)^N`、N は右端がちょうど +6 dB になる値）で、**0 dB がスライダーの 80% の所**（縦線）、左端が −∞。エンジンの `gain_db` は −60〜+6 で、**−60 は無音（−∞）** |
| パン | **L100〜C〜R100**（エンジンの `pan` は −1〜+1）。ノブは 7 時〜5 時、中央から値の側へ弧を描く |
| 既定値に戻す | どちらも**ダブルクリック**（2 回押し）で 0 dB・C。0 dB の近く（±0.15 dB）とパンの中央（±2）には吸い付く |
| 細かく | **Shift** で動きの 1/10（吸い付きも外れる）。Alt は使わない（クリップの位置の Alt と意味をぶつけない）。**ホイールでは変えない**（トラックビューの縦スクロールとぶつかるため） |
| つまみの動き | 音量は横にドラッグ（つまみ以外を押すとそこへ移して、そこからの差で動かす）。パンは上下にドラッグ（上 = 右。横に動かしても効く）。**ドラッグ中は値の吹き出し**（「−3.5 dB」「L 30」。出す・消すだけで動かさない） |
| キー | 音量: ←→（↑↓）で 0.5 dB・Shift で 0.1 dB・Home で 0 dB・End で −∞。パン: ←→ で 5・Shift で 1・Home で中央。どちらも ←→ をノート・再生位置のコマンドに渡さない |
| 読み上げ | どちらも `role="slider"`。名前は「<トラック名> の音量」「<トラック名> のパン」、値は「−3.5 dB」「左 30」。**M・S の `aria-label` にもトラック名**を足した（「<トラック名> のミュート」） |
| 聞こえないトラック | ミュート・ソロで聞こえないトラックは、スライダー・ノブ・数字を 0.45 に薄くする（値は残り、触れば変えられる） |
| 高さが小さいとき | トラックの高さが **40 px 未満**（縦ズームで 28 px まで）なら 2 段目を畳む。値は名前のツールチップ（「… — 音量 −3.5 dB・パン L 30」）に出す |
| ホバーに頼らない | 新しい部品はどれもいつも見えている（タッチでも使える） |

**聞こえ方（`audio.js`）**: 再生だけに効く。トラックごとに `GainNode`（ミュート／ソロの 0／1 × 音量）→ `StereoPannerNode`（パン）→ 出力。
ドラッグ・キーのたびに `setTargetAtTime` で数 ms かけて当てるので、再生中に動かしてもプチッと鳴らない。
モノラルの音は StereoPannerNode の等パワーで中央が −3 dB になるので、モノラルだけ √2 を掛けて中央を 0 dB にそろえている
（パンを触る前と同じ音量。ステレオの音は中央で変わらない）。

**書き出しには入れない**（決めたこと）。`export_wav`・`render_tracks` の音のファイルは今までどおり編集したボーカルの中身そのもの
（DAW に戻して混ぜる前提）。入れるなら `export.py` に gain を掛けるだけで、パンはモノラルのボーカルには掛けない。

**取り消しと保存**: 単体版の音量・パン・M／S は変更ごとに履歴へ入り、Ctrl+Z／やり直しで戻る。幅は表示設定なので対象外。
音量・パンは M／S と同じく **session（`session.json`・`.gliss`）に保存**し、変えると未保存の印が付く。ARA の DAW ミキサーは Gliss の履歴に入れない。
画面では順番待ちに入れず、その場で音に当てる（`setMix`）。エンジンへは 1 本ずつ・最後の値だけ送る（ドラッグ中に毎回 `session.json` を書かない）。
値を変えると見出しを作り直すので、ドラッグは `window` の `pointermove`／`pointerup` で追い、2 回押しは押下の間隔（400 ms）で見る。

**見出しの幅**

| もの | 決めたこと |
|---|---|
| 範囲 | **140〜min(360, トラックビューの幅の 40%)**、既定 160 px。**全体で 1 つ**の設定（曲ごとではない）。ルーラーの左の空き（`.rhd`）も同じ幅で動く |

## 4. クリップの横ドラッグで音源全体の位置をずらす

決定コメント（2026-09-23）で、モックの「録った位置を保つためクリップは動かさない」を変えた。
スクリーンショット: `app/screenshots/screenshot-tracks-move.png`（テイク・ガイド・伴奏をそれぞれずらしたところ）。

### 操作

- **クリップの下半分を横にドラッグ**で、そのトラックの音源全体の位置をずらす（どの種類のトラックでも）。
  **上半分のドラッグは範囲**（下をズーム）。Studio One／Fender Studio Pro のスマートツール（イベントの上半分 = 範囲、
  下半分 = 矢印）と同じ分け方で、見た目の要素は足していない（下半分ではカーソルが手の形になり、ツールチップ
  「ドラッグで位置をずらす（Shift: 細かく / Alt: 吸い付かない）」が出る）。理由は §7。
- ドラッグ中はずらした量（元の位置からの秒、`+0.120 s`）をクリップの左上に出す。
- **Shift で細かく**（1/10。途中で押しても跳ばない）。**元の位置（0）に吸い付く**のは 6 px 以内かつ 30 ms 以内だけ
  （曲全体を 1 画面に出すと 6 px が 1 秒近くになり、レイテンシ程度のずらしができなくなるため）。Shift・Alt の間は
  吸い付かない。吸い付く先は 0 だけ（他のトラックの頭・拍には吸い付かない）。
- 見出しの右クリック > **元の位置に戻す**（位置を 0 に）。
- **ドラッグ中の見た目 = 離した後**: 離してからエンジンの値が返るまで見かけの位置を残す。上の目盛りはドラッグ中は
  止め（手の動きとクリップを 1:1 に）、離した後もクリップがはみ出したときだけ広げる。編集中のトラックなら、ドラッグ中に
  下の目盛り・再生位置も動く。再生中なら、離した後に今の再生位置から鳴らし直す。
- **Ctrl+Z / Ctrl+Shift+Z** で戻す／やり直す（ノートの編集と同じ取り消しの列に入る。ツールバーの取り消しも効く）。

### 位置の扱い（決めたこと）

| 対象 | 扱い |
|---|---|
| 持ち方 | トラックの `offset_sec`（タイムライン上の位置、秒。負も可）。**音声ファイルは書き換えない**（非破壊） |
| 編集 | **音と一緒に動く**。編集の秒はトラックの頭が 0 のまま（ずらしても編集リストは変わらない） |
| ガイドとの対応 | **タイムライン上の位置で取る**（§1 のガイドの重ね方）。テイクかガイドをずらすとプロジェクトを開き直してガイドの解析と対応付けをやり直す（3.8 秒の素材で 0.3 秒ほど）。ガイドの歌詞はガイドのトラックにファイル上の秒で控えて、切り出しの位置に合わせて入れ直す（前へずらして外に出た区間も、戻せば戻る。ガイドを外して付け直しても戻る） |
| 再生 | ずらした位置で鳴る（`render_tracks` の `start_sec`） |
| 書き出し | **中身・長さは元のまま**（DAW に戻すファイルの約束を変えない）。**BWF の TimeReference（DAW 上の位置）だけをずらした量だけ動かす**。元に bext が無くても足す。前へずらして 0 より前になるときは 0 にして警告。ステータス行に「位置 +0.120 秒ずらした」 |
| DAW 往復 | `_ve.wav` を DAW に戻して「元の位置へ」（Fender Studio Pro のインスペクター・Reaper の *Move to source preferred position*）で、**ずらした後の位置**に来る。ずらしていなければ今までどおり元の位置。**DAW に効くのは書き出すテイクの位置だけ**（伴奏・ガイドをずらしても DAW 側は変わらない。DAW で合わせたいならテイクの方をずらす） |

- **DAW で途中から録ったテイク**（bext の TimeReference が 0 でない。Studio One の録音は録音を始めた位置が入る）も、
  トラックビューでは他と同じくファイルの頭を 0 に置く（初期位置を TimeReference から決めることはしていない。§7 残課題）。
  そのため曲頭から始まる伴奏とは、画面の上では録音を始めた位置のぶんずれて見える・鳴る。これを合わせるためにテイクを
  ずらして書き出すと、TimeReference は「元の値 + ずらした量」になって DAW では二重にずれるので、**書き出しで警告を出す**
  （「元の WAV には DAW 上の位置（108.200 秒）が入っている…」）。この場合 DAW では「元の位置へ」で置いてから手で合わせる。
- **issue #12（ガイドに合わせるのタイミング。main に取り込み済み）との関係**: #12 はガイドを「ガイドの時刻（プロジェクトの
  中の秒）＋全体のずれ（発音の頭どうしの差の最頻値）」で描き、「ガイドに合わせる」は全体のずれを除いた所ごとのリズムだけを
  揃える。トラックビューはガイドをタイムライン上の位置で切り出して渡すので、**トラックの位置をずらした量はそのまま
  #12 の全体のずれに入る**（3.8 秒の素材で、テイクを前へ 0.2 秒ずらすと全体のずれが −5 ms → −210 ms）。
  **issue #61 で変えた**: 全体のずれが 150 ms 以内なら、「ガイドに合わせる」の目標と画面のガイドは**タイムライン上のガイドの
  位置そのもの**（ずらした量ごと合わせる。以前は全体のずれに吸われて、ずらしても目標が変わらず、テイクが全体に遅れて
  いるとガイドに合っていた頭まで遅らせた）。150 ms を超えてずらしたときだけ、以前どおり置き場所の違う素材として
  「ガイドの頭＋全体のずれ」（`docs/guide-timing.md` §9）。
  短い素材では、ガイドを切り出すと頭の部分の中身が変わるので全体のずれの推定がぶれることがある（同じ素材で後ろへ
  0.25 秒ずらすと +0.40 秒と出た。発音の頭の組が 5 つしか無いため）。
- 前へずらせるのは、録音の遅れ（レイテンシ）を直すような「テイクだけ早める」をしたいため（DAW のように 0 で止めない）。

## 7. 判断（モックから変えた点）と残課題

### 判断

- **クリップ = 音声ファイル 1 本**（録音ファイルの長さ）。モックはフレーズごとにクリップがあるが、実際の録音ファイルは
  曲のほとんどが無音でも 1 本なので、DAW と同じくファイルの長さのクリップにした。その代わり、クリックで下に出すのは
  **クリックした所の歌っているかたまり**（全体の波形から）にした（158 秒のファイルでクリップ全体を出すと何も読めない）。
- **位置の移動はクリップの下半分、範囲は上半分**（Studio One／Fender Studio Pro のスマートツールと同じ向き）。クリップが
  レーンのほぼ全部を覆うので、「クリップ上 = 移動、空き = 範囲」ではモックの範囲ドラッグができなくなるため。見た目の要素は
  足さず、カーソル（手の形）とツールチップだけで示す。
- **ガイドの色はグレー**（モックは水色）。エディターのガイドが issue #1 でグレーに決まっているので上下でそろえた。
- **編集はトラックごとのプロジェクト、プロジェクトの形は変えない**。既存の MCP ツール・画面の編集・書き出し・
  アーカイブ（`to_archive`）がそのまま使える。複数トラックは `session.json` と MCP の層だけで扱う。
- **書き出しの位置**: 中身・長さは元のまま（DAW に戻すファイルの約束を変えない）、TimeReference だけ動かす。
  中身をずらす（頭を削る・無音を足す）と、元のファイルと差し替えたときに長さが変わり、「非編集区間はビット単位で同じ」も
  崩れるため。
- **既定は全トラック鳴る**（DAW と同じ。ガイドだけ既定でミュート、はしていない）。
- **上のタイムラインの既定は全体を 1 画面**（モックと同じ）。細かい位置合わせは Shift の 1/10 で。issue #39 で、上だけの
  横ズーム・横スクロール（下のエディターとは別。ホイールの割り当ては共通で、ポインタのある側に効く）を足した。
- **トラックの並び順**（issue #38）: 見出しを上下にドラッグ。`session.json` のトラックの並びをそのまま変える
  （`set_track(index)`。取り消しの履歴に入る）。並びは見た目だけ。
- **どのトラックを編集しているかはプロセスごと**（画面と Claude Code が別のトラックを同時に編集できる）。

### 残課題

1. ~~画面のガイドは #12 の「ガイドの時刻＋全体のずれ」で描くので、位置をずらしても下の重なり方はほぼ変わらない~~
   → issue #61 で、全体のずれが 150 ms 以内ならタイムライン上の位置で描き、補正もそこへ合わせるようにした（§4）。短い素材での全体のずれの推定のぶれは、150 ms の境目の判定に効くので残る。main（#12 のマージ 2cfc6ee）を取り込んだ。衝突は README だけ。
   #12 の発音の頭のキャッシュはガイドの範囲を鍵に持つので、ずらすと取り直される（ガイドを外す・外部が差し替えたときも捨てる）。
2. ガイドの位置・指定を変えるたびにガイドの解析（F0 と DTW）をやり直す（3.8 秒で 0.3 秒、158 秒の曲で数秒）。
   ソースごとに F0 をキャッシュして切り出しだけ変える、は未実装。
3. ガイドのトラック自身を編集しても、他のテイクに重ねるガイドは元の音（編集前）。
4. 再生はトラックごとに曲全体の音を読み込んで混ぜる（158 秒のステレオで 1 トラック 60 MB ほどのメモリ）。編集した
   トラックは編集が変わるたびに曲全体の音を書き直して読み込み直す（エンジン側は §6 の実測。画面の読み込みは未計測）。
   遅ければ、変わった窓だけ差し替える形にする。
5. 位置の数値入力・他のトラックの頭への吸い付きは無い（並べ替えは issue #38、上のタイムラインのズームは
   issue #39、名前の変更は issue #17、音量／パンと見出しの幅は §3.1 で足した）。音量・パンの数値入力と、書き出しへ入れることは無い。
6. 1 トラック = 1 ファイル（部分ごとに動かす・詰める・消す・複製する本物の複数クリップは無い。切れ目と部分のミュートだけは §8）。
   ファイルの一部を開くクリップ（`open_project` の `offset_sec`）はセッションに入るが、画面から作る操作は無い。ガイドがクリップのとき、テイクがガイドのクリップより前に
   はみ出すと、クリップの外（ファイルの実際の音）が入る。
7. 初期位置は 0（曲頭 0:00 起点のファイルの前提のまま）。**BWF の TimeReference から DAW 上の位置に置く、はしていない**
   （§4。DAW で途中から録ったテイクは、画面で伴奏とずれる・ずらして書き出すと警告）。
8. 外部（Claude Code）がトラックを変えたときは `session.json` の監視で読み直す。画面と Claude Code が同時に同じ
   トラックの位置を変えると後に書いた方が勝つ（project.json と同じ）。相手のプロセスが、こちらで編集中のトラックを外した・
   伴奏にしたときは、書き出しの位置のずらしが 0 になる（警告は出ない）。
9. 負のオフセット（`pad`）のガイドを持つ project.json は、この版より前のエンジンでは開けない（版番号は上げていない）。
10. `render_view` の題・`list_deviations` などの秒はトラックの頭が 0 の秒のまま（タイムライン上の位置は `list_tracks` で）。

## 8. はさみ・ミュートツールで上のクリップを分ける・部分を消す（承認済み（2026-10-03））

下のピアノロール（ノートの分割・無音）と同じツールを、上のトラックビューでも使えるようにした（案 02-A「切れ目 + 部分のミュート」。
本物の複数クリップ = 部分ごとに動かす・詰める・消すは作らない。解析・ガイドとの対応・`render_tracks` には触らない）。

### 操作

| ツール | 上（トラックビュー） |
|---|---|
| 1 メイン | 今まで（§3・§4）のまま |
| 2 鉛筆 | メインと同じに働く（上で描くものが無い。カーソルも矢印） |
| 3 はさみ | クリップをクリックで分ける（ホバーで縦線）。切れ目のダブルクリックでつなぐ。時間スナップ（N）がオンならグリッドに寄せる（Shift で外す）。両端から 20 ms 以内は断る。ボーカルにも伴奏にも効く |
| 4 ミュート | 部分（切れ目で分けた区間。分けていなければクリップ全体）のクリックで消す⇔戻す。押したまま横になぞると、最初に押した部分と同じ向きにそろえる（行をまたいでよい。1 回の Ctrl+Z） |

- カーソルは、はさみ・ミュートはクリップの上だけツールの絵（外は矢印）。鉛筆はいつも矢印。ツールを替えるとステータス行に
  下と上の働きが出る（`tracks.js` の `TOOL_STATUS`）。クリップの外ではメインと同じ（再生位置が動く）。
- 描画: 切れ目は 2 px の隙間。消した部分は点線の輪郭＋薄い波形（0.78 の暗い覆い）＋スピーカー×（幅 22 px 超）。
  下のピアノロール（`draw.js` の `clipMuteBands`）には「クリップで消している」斜線の帯を重ねる（ポインタは素通し）。
- 見かけはすぐ変え（`clipedit.js`。エンジンと同じ規則）、エンジンの呼び出しを順番待ちに入れて、返り値のセッションで置き換える
  （失敗したら `list_tracks` で合わせ直す・順番待ちの間に Ctrl+Z されたら見かけを戻す）。

### 持ち方（`session.json` の版は 1 のまま。足しただけ）

- トラックの `cuts: [秒…]`（切れ目）と `mutes: [[始め, 終わり]…]`（消した区間）。どちらも**トラックの頭（クリップなら頭）が 0 の秒**で、
  編集の秒と同じ。ファイルを丸ごと開いたトラックでは「ファイルの中の秒」と同じ。`offset_sec` で動かしても値は変わらず、タイムライン上で一緒に動く。
- 整え方（`session.py` の `norm_cuts` / `norm_mutes`）: 範囲の中だけ・昇順・1 ms より近い切れ目は 1 つ・重なる／接する消した区間は 1 つにまとめる。
  部分が消えているかは「消した区間で全部覆われているか」で見る（MCP で任意の範囲を消しても矛盾しない）。
- 取り消しの対象（`structure()` に入る。ミュート／ソロ・位置・並びと違って聴き比べの操作ではない）。`list_tracks` が返す。
- MCP: `split_track(track_id, sec)`・`join_track(track_id, sec, tolerance_sec?)`・`mute_track_range(track_id, start_sec, end_sec, mute?, group?)`
  （[MCP.md](../engine/docs/MCP.md) §3-2。AI の許可は「編集」）。つなぐとき、両側が消えていれば消したまま、片側だけなら戻す。

### 再生・書き出し

- 再生（`audio.js`）: ミュート／ソロの GainNode とは別に、トラックごとにもう 1 つ GainNode を挟み、消した区間だけ 0 にする
  （区間の外側 5 ms でフェード。ループの周回ごと・再生中に消したときも今から先の分を予約し直す）。伴奏にも効く。
- 書き出し（`render/export.py` の `apply_mutes`）: **編集中のボーカルの消した区間を 0 にし、前後 5 ms をフェードにする**（区間の外側に置くので、
  区間の中は完全な 0、フェードより外は元のサンプルのまま）。返り値の `muted_spans_sec`・警告に件数。ノートの「無音」（編集）とは別。
  伴奏・他のボーカルはエンジンが書き出さないので、再生だけ。

### 決めたこと・残課題

- 消した部分の書き出しは「効かせる」（聞こえているとおりに書く）。再生だけにしたければ、ノートの無音ではなくこの区間を戻す。
- 部分ごとに動かす・詰める・複製するは作らない（本物の複数クリップ。session の版を上げる別の作業）。
- 他のボーカルのトラックの書き出し・伴奏のミックスの書き出しは無い（再生だけに効く）。
- 見出しの音量・パン・幅（別の作業。`headsHtml` と見出しの操作には触っていない）。

## 9. トラックごとのガイドのプルダウン（2026-10-07）

1 つの曲で、主旋律・ハモリ・囁きなどが**それぞれ別のガイド**に合わせられるようにした（エンジンの `set_track_guide`。
トラックの `guide_id`・`effective_guide_id`・`is_guide`・`guide_for`。[MCP.md](../engine/docs/MCP.md) §3-2）。
共通のガイド（`set_guide_track`）は「ガイドを選んでいないトラックが合わせるもの」として残す。

### 置き場所（決めたこと）

- **見出しのガイドのボタンをプルダウンにした**（`tracks.js` の `headsHtml`・`menus.js` の `guideItems`）。ガイドはトラックの
  性質なのでトラックの行に置く。編集対象を切り替えずに、ほかのトラックのガイドも決められる（プラグインは十数本並ぶ。
  切り替えるたびに解析を開き直すのは重い）。ツールバーは 360 px 幅で右側が切れるので置かない。
  - 単体: 1 段目の M・S の左の**アイコン＋▾のボタン**（今までホバーで出ていたガイドのアイコンの場所。常に出す）。2 段目は音量・パンのまま。
    今のガイドはボタンのツールチップと読み上げの名前（「vo-hamo のガイド: 共通のガイド（vo-main）」）。自分で選んだときは少し明るく。
  - プラグイン: M・S・音量・パンが無く 2 段目が空くので、そこに**今のガイドの名前つきのボタン**（ガイドのアイコンに続けて「共通（vo-main）▾」「vo-hamo+3 ▾」）。
    十数本でもどのトラックが何に合わせているかが一目で分かる。高さを詰めて 2 段目を畳んだときは 1 段目のアイコンのボタンに替わる。
- **プルダウンの中身**（右クリックのメニューと同じ見た目・キー操作。`menuitemradio`）:
  1. 「共通のガイド（<名前>）」＝ `guide_track_id: null`。共通のガイドが無ければ「なし（共通のガイドも未指定）」、
     そのトラック自身が共通のガイドなら「なし（このトラックが共通のガイド）」。
  2. ほかのボーカルのトラック（見出しと同じ並び。自分と伴奏は出さない）。プラグインは右に DAW のトラック名（修飾の名前と違うとき。
     同じ名前の修飾が並んでも見分けられる）、共通のガイドのトラックには「共通のガイド」と添える。
  3. 「このトラックを共通のガイドにする」／「共通のガイドから外す」（`set_guide_track`。今までのアイコンの働き）。
- 見出しの右クリックは「ガイドを選ぶ…」（同じプルダウンを出す）と「このトラックを共通のガイドにする」。
- 「ガイド」の印: **どれかのトラックのガイドになっているトラック**のクリップの左上に「ガイド」の札（レーン。見出しに置くと、
  単体の 1 段目の名前が削れて 360 px 幅で読めなくなったので移した）。見出しの名前のツールチップに「ガイド: ○○ が合わせる」。
- レーンの灰色（エディターのガイドと同じ色）は**編集中のトラックのガイド**（今までは共通のガイド）。下に灰色で重なるものと同じ。
- ステータス行の「/ ガイド: 名前」はガイドのトラックの名前（今まではファイル名）。重ならない理由の文も「見出しのガイドのボタン」に合わせた。

### 動き

- 選ぶと、見出しはすぐ選んだ値で描き（エンジンの答えを待たない）、`set_track_guide` を順番待ちに入れる。編集中のトラックなら
  エンジンが開き直す（`reopened`）ので、ガイドとの対応付けをやり直してガイドの線・ずれの表示・「ガイドに合わせる」が新しいガイドに替わる。
  ほかのトラックなら見出しと札だけが替わる（裏の準備が新しいガイドで入れ直す）。
- 取り消しの履歴に 1 つ（「ガイドの指定」）。Ctrl+Z / Ctrl+Y で戻る・やり直す（編集中のトラックなら開き直す）。
- 失敗したら見出しを元の選択に戻し、ステータス行に「○○ のガイドを変えられなかった（元に戻した）: 理由」。
- キーボード: ボタンに Tab で来て Enter・Space・↑↓ で開く。開くと今の選択にフォーカス、↑↓ で移って Enter、Esc で閉じてボタンに戻る。
  開いている間に同じボタンを押すと閉じる。メニューは画面の高さを超えるときスクロールする。
